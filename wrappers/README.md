# LCEVCdec Wrappers

Certain integrations of the LCEVC decoder require wrappers and interfaces to port the C and C++ APIs to languages and build systems native to other platforms. These wrappers are stored here in the LCEVCdec repo to couple the versioning of wrappers to the LCEVCdec version and allow integrated build pipelines. Wrappers are not built by default or required for the core library support. Details of how to build each wrapper are included in the wrapper's readme.
